# Queen's Student Page

Personal student page for CISC 121 (Homework 2), built with plain HTML and CSS and deployed with GitHub Pages.

Live site: https://coffeee339112.github.io/queens-student-page/

## Files

- `index.html` — page content (About Me, Courses, Projects, Interests, Contact)
- `style.css` — Queen's colours, layout and styling
- `me.jpg` — profile photo

## How to update

1. Edit the text in `index.html` (keep new sections inside `<main>`).
2. Edit colours or spacing in `style.css`.
3. Commit the change. GitHub Pages redeploys the site automatically within a minute or two.
